## Overview
Hybrid dark+light keynote identity: cinematic deep-ocean cover and closing moments paired with crisp maritime paper analytical slides.

## Colors
- Light analytical palette (`#F4F7FA` / `#FFFFFF` / `#0C2340`) + Dark focal palette (`#061527` / `#0F2540` / `#38BDF8` / `#2DD4BF`).

## Do's and Don'ts
- **Do** use per-slide `design.background` when switching between dark and light slides so native accessibility contrast stays accurate.
- **Don't** repeat `fade` on every slide.
